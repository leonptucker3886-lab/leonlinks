# Head-to-Head II: Tool Status Strip (MAJ Pizzapan)

Branch: pizzapan/h2h2-tool-status-strip (not merged to main)

## What it adds
A thin strip above the home-page nav showing Home, Editor, ClearCopy and GitHub with a green/red dot from a live in-browser check.

## Known limits
- ClearCopy and GitHub dots only show whether the site responds (browser CORS blocks reading real status).
- No Vercel preview verified yet.

## Pitch
One glance tells you which of your tools are up before you click. No login, no dashboard, zero setup.
