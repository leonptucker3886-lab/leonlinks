# Leonlink

Free, open-source link-in-bio page maker (a Linktree alternative). One HTML file, no backend, no fees.

Live demo: https://leonlink.vercel.app

## Features
- 15 themes: Norse, Military, Manager, Executive Gold, Cyberpunk, Tech Startup, Minimal, Nature, Ocean, Retro 80s, Medical, Legal, Real Estate, Creative Studio, Sports/Coach
- Live editor (name, title, bio, crest/logo, links, reorder) that autosaves in your browser
- Share link, export your page as one file, and a vCard "Save Contact" button
- Animations: boot-up glow, staggered links, rune scramble, tap ripple. Respects reduced-motion settings

## Compared with other link-page apps
What users complain about elsewhere, and how Leonlink handles it:
- **Custom domains cost money** (Linktree Pro is about $15/mo). Here you export the page and host it on any domain for free.
- **Sales fees** (Beacons takes 9%). Leonlink takes nothing.
- **Slow, heavy pages** on Firefox and mobile. This is one small static file.
- **Forced branding and same-looking templates.** There's no watermark, and you get 15 distinct themes.
- **Privacy.** There's no tracking. Click counts stay on your own device.

## Run / deploy
Open `index.html`, or deploy the repo on Vercel or Netlify, or with GitHub Pages.
